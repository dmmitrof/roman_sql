«Что такое SQL»

SQL = способ задать вопрос данным

  вопрос  →  [ база данных ]  →  ответ (таблица)

«SQL — это язык вопросов к данным. Не язык программирования в обычном смысле — вы не пишете алгоритм, вы описываете, что хотите увидеть».

«Ответ на любой запрос — всегда таблица: строки и столбцы. Даже если одна строка или одна ячейка».

«Две таблицы»

PK — Primary Key (Первичный ключ)
У любой нормализованной таблицы должен быть PK. PK однозначно определяет строку в таблице

FK — Foreign Key (Внешний ключ)
FK — это ссылка на PK в другой таблице

customer_id — это как номер пропуска, по нему можно найти человека в двух разных списках

customers                          orders
┌─────────────────────┐            ┌─────────────────────────┐
│ customer_id  PK     │◄───────────│ order_id       PK       │
│ name                │            │ customer_id    FK       │
│ city                │            │ order_date              │
│ signup_date         │            │ product                 │
└─────────────────────┘            │ quantity                │
                                   │ price                   │
                                   └─────────────────────────┘

«Одна строка в customers = один клиент. Одна строка в orders = один заказ».

«customer_id — это номер пропуска. В customers он уникален (PK — primary key), в orders он повторяется (FK — foreign key), потому что один клиент может сделать много заказов».

«По этому номеру мы потом склеим таблицы».

«SELECT: выбираем столбцы»

FROM     таблица;

«SELECT * — все столбцы. SELECT name, city — только эти».

«Регистр ключевых слов не важен, но пишем заглавными — привычка».

«Точка с запятой — конец запроса».

«WHERE: фильтр»

SELECT   ...
FROM     ...
WHERE    условие;

строки в кавычках:  'Москва'
числа без кавычек:  20000

SELECT *
FROM customers
WHERE city = 'Казань';

SELECT *
FROM orders
WHERE customer_id = 5;

«WHERE — это как фильтр в Excel. Оставляет только строки, где условие истинно».

«Строки — в одинарных кавычках. Числа — без. Забудете кавычки — SQLite скажет no such column».

«ORDER BY + LIMIT: сортировка и топ»

ORDER BY  столбец        -- по возрастанию
ORDER BY  столбец DESC   -- по убыванию
LIMIT     N              -- только первые N строк

SELECT *
FROM customers
ORDER BY city
LIMIT 5;

«ORDER BY — сортировка в Excel. ASC — по возрастанию (по умолчанию), DESC — по убыванию».

«LIMIT — обрезать результат. Вместе с ORDER BY DESC — это “топ-N”».
